# CourseHub

Вебсервіс-агрегатор онлайн-курсів Udemy, Coursera та edX (лабораторна робота №4 з JRPZ).

Повний опис структури, команди та інструкції із запуску з'явиться після злиття pull request
гілки `feature/CH-21-deploy-ci`. Код розділено за гілками учасників команди, правила роботи з
гілками й код-рев'ю описано в шаблоні pull request.
